Meet Arachne.

Arachne is a personal Windows AI assistant designed to make everyday computer work simpler. It combines AI, memory, voice, web search, screen understanding and supported PC automation in one system.

Privacy PolicyTerms of Service

What Arachne does

Arachne is built around one assistant that can understand a request, use the appropriate tool and return control to you.

Conversation

Answers questions, explains concepts, helps plan tasks and works with information you provide.

Windows control

Can perform supported local actions such as opening applications, controlling media and navigating Windows features.

Screen understanding

Can inspect the visible screen when a task requires understanding what is displayed.

Voice

Supports voice interaction so you can communicate without constantly typing.

Web search

Can use search services when current public information is needed.

Memory

Can store selected information needed to make future conversations more useful.

Google integrations

Arachne may connect to Google services when you explicitly authorize an integration. For Google Calendar, the planned feature uses read-only calendar access when viewing is all that is required.

Your authorization matters. Google account access is controlled through Google's OAuth permission system. Visiting this website does not grant Arachne access to your Google account.

Personal project

Arachne is currently a personal project. Its goal is to provide a practical assistant for a user's own computer and workflows rather than operate as an advertising platform or social network.

Privacy Policy

Last updated: September 17, 2026

Important: This is a project privacy-policy template, not legal advice. Before publishing Arachne for other users, make sure every statement matches the actual software and data flows and consider having the final policy reviewed by a qualified adult or legal professional.

1. Overview

Arachne ("Arachne", "we", "us", or "the application") is a personal AI assistant for Windows. This Privacy Policy explains what information Arachne may process, why it is processed, and how information may be handled when users use Arachne or connect third-party services.

2. Information Arachne may process

  • Messages and requests entered into Arachne.
  • Voice input when voice interaction is used.
  • Information visible on the computer screen when screen-understanding features are explicitly used.
  • Selected memory information retained to make future conversations more useful.
  • Technical information needed to operate the application, such as logs or error information.
  • Information from third-party services that the user explicitly connects and authorizes.

3. Google user data

If you connect a Google service, Arachne may receive data from that service only after you authorize access through Google's OAuth authorization process.

For Google Calendar, Arachne is intended to request the minimum access necessary for the calendar feature. When the feature only needs to view calendar information, Arachne uses read-only calendar permission rather than permission to create, edit or delete calendar data.

Google user data is used only to provide the Google-integrated functionality described in Arachne. Arachne does not sell Google user data or use it for advertising.

Arachne will not use Google user data for a purpose unrelated to the feature for which the user granted access. If the architecture changes, this policy will be updated to reflect the new practice.

4. AI providers

Arachne may send a user's request or necessary context to an AI model provider to generate a response. The provider can change as the project evolves. Only information necessary for the requested feature should be sent.

5. Memory

Arachne may store selected information in its memory system so future conversations can be more useful. Memory should be limited to information necessary for the assistant's intended functionality.

6. Local computer access

Arachne can be configured to interact with the user's Windows computer. This may include opening applications, navigating supported interfaces, controlling media or reading visible screen information. These capabilities are intended to operate only when requested or otherwise authorized by the user.

7. Sharing

Arachne does not sell personal information. Information may be transmitted to service providers when necessary to operate a feature, including AI, search, hosting, database, automation or Google services explicitly connected by the user.

8. Data retention

Retention depends on the feature and technical systems used by Arachne. A production release should document exact retention periods for account data, memory, logs and third-party tokens. This policy should not be treated as a guarantee of a specific deletion timeline until those periods are formally established.

9. Security

Arachne uses reasonable technical measures intended to protect information. No internet-connected system can guarantee absolute security. Users should not provide passwords, authentication codes, payment information or other highly sensitive credentials to Arachne unless a specific feature has been designed and disclosed for that purpose.

10. Third-party services

Arachne may integrate with third-party services including Google and AI, search, hosting, database or automation providers. Those services have their own privacy policies and terms.

11. Children's privacy

Arachne is not intended to be a service for collecting personal information from children. If Arachne is later offered publicly, the operator should establish an age-appropriate privacy and consent process before allowing public accounts or broad data collection.

12. Changes

This Privacy Policy may be updated when Arachne's features, integrations or data practices change. The "Last updated" date will be changed when material updates are made.
